# 🛒 Sistema de Gestão de Mercado

Projeto prático em Java desenvolvido para consolidar os fundamentos da linguagem, lógica de programação e boas práticas de desenvolvimento Back-end.

O sistema evolui de uma aplicação em linha de comando (CLI) até uma futura API REST com Spring Boot e banco de dados.

---

## 🚀 Funcionalidades Atuais (Semana 1)

- [x] **Cadastro de Produtos:** Nome, preço e quantidade em estoque.
- [x] **Controle de Estoque:** Cálculo automático do valor financeiro total em estoque e alertas de reposição para estoque baixo.
- [x] **Menu Interativo:** Navegação via terminal utilizando `do-while` e `switch/case`.
- [x] **CRUD Completo em Memória:**
    - `Create`: Adicionar novos produtos dinamicamente com `ArrayList`.
    - `Read`: Listar todos os produtos e buscar produtos por nome (`contains`).
    - `Update`: Atualização de informações de produtos por índice.
    - `Delete`: Exclusão de itens da lista por índice.
- [x] **Modularização:** Separação de responsabilidades em métodos dedicados.
